Create and update the plan list for the current session. The user sees it pinned under the conversation and follows your progress on it while you work.

Use it for every request with several steps (implement and test, investigate then fix, a list of tasks from the user). Write the whole plan before your first other tool call: short imperative steps of a few words, in the order you will do them. Skip it for a single small change, a question or conversation.

- Send the full list on every call; it replaces the previous one.
- Keep exactly one step `in_progress` while you work. When a step is actually done, mark it `completed` and the next one `in_progress` in the same call.
- When the plan changes (new instruction from the user, a step turns out unnecessary), send the new whole list; mark dropped steps `cancelled` instead of deleting them.
- When everything is done, mark the last step `completed` so no step stays `in_progress`.
- Only call it when the list changes.
